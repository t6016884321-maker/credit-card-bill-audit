# 检查规则 C01–C18、证据分级与常见误报

规则表的机器可读版本在 `assets/rules.json`，由 `scripts/check_compliance.py` 执行。
每条规则产出 `status`、`fact`、`amount`、`evidence_strength`，并生成一条编号质询。

## 1. 三种状态的含义（不得混用）

| 状态 | 含义 | 在函件里怎么写 |
|---|---|---|
| `hit` | 账单数据里**确实检出**该事实 | 列出期次、笔数、金额，要求银行说明依据或退还 |
| `clean` | 已核查、未检出 | **也要写进报告**，这是可信度的来源；函件里可不再质询 |
| `need_evidence` | 账单本身**无法证明**，需银行提供其掌握的记录 | 用「请提供…」「请说明…」，绝不写成「贵行已违规」 |

## 2. 证据强度分级

| 级别 | 判定 | 可否主张退还 |
|---|---|---|
| 强 | 账单白纸黑字 + 明确违反现行有效规范（如 2017 后仍收滞纳金） | 可列入 A 层直接主张 |
| 中 | 账单有线索但需逐日明细/合同/披露页佐证 | 列入 B 层，待举证后核算 |
| 弱 | 仅为统计相关或粗算（隐含日利率、同日同额、成本占比） | 只作调单与索证线索，不写金额主张 |
| 程序性 | 时效、留痕、发票、答复时限 | 不计入退费金额 |

## 3. 规则清单与 detector 映射

| ID | 检查点 | 自动判定依据 | 常见误报 |
|---|---|---|---|
| C01 | 2017-01 后滞纳金/超限费 | `period >= 2017-01` 且名目命中 | 2017 年前的滞纳金当时合规，不能算 |
| C02 | 违约金另签协议 | 有违约金即 `need_evidence` | 账单无法证明「没签」，只能索证 |
| C03 | 服务费计入计息基数 | 有利息即 `need_evidence` | 不能从利息金额反推基数构成 |
| C04 | 年费重复/减免未落实 | 同一年正扣 >1 次为 `hit`；否则 `need_evidence` | 一年一次年费本身不违规，要查卡种减免条件 |
| C05 | 未授权增值服务费 | 分类为「增值服务费」 | **「(消费)…保险经纪」是刷卡消费，不是银行收费**；慈善短信捐赠也不是银行收费 |
| C06 | 过渡期后仍用「手续费」名义 | `period >= 2024-07` 且分类为分期手续费 | 账单注释文字里出现「手续费」不算命中，只看交易名目 |
| C07 | 自动分期缺逐笔授权 | 交易摘要含「自动」+「分期」，或 PDF 全文含自动分期声明 | 声明「已绑定」不构成授权；也不要把过渡期当豁免 |
| C08 | 年化利率披露 | 全文扫「年化」次数（间接证据） | **月度账单不是法定展示位置**，0 次≠违法 |
| C09 | 利率自主协商记录 | 固定 `need_evidence` | 2021-01-01 之后才适用 |
| C10 | 隐含日利率异常 | `interest ÷ prev_balance ÷ days > 0.5‰/日` | 粗算，含分期息费时会失真；只作索证线索 |
| C11 | 疑似重复交易 | 同日 + 同额 + 同摘要前 30 字 | 分期成立、消费与冲账成对出现属正常；**必须调单确认** |
| C12 | 无摘要调账 | 分类为其他冲账且摘要为空 | 「分期冲帐」是冲回原消费，不是提前结清 |
| C13 | 额度调整 | `credit_limit` 变动次数 | 升降成对多为临时额度到期恢复；银行并非绝对无权调额 |
| C14 | 积分抵扣年费 | 有年费返还即 `need_evidence` | 多数银行**无自动全额抵扣义务**，只能谈规则告知与未兑换年度提醒 |
| C15 | 息费畸高调减 | 固定 `need_evidence` | 「息费/净消费」是占比不是综合年化，不能直接套 24% |
| C16 | 索取原始申请材料 | 固定 `need_evidence` | 银行不得以「年代久远/系统无记录」推脱（投诉办法 13 条） |
| C17 | 开具历史发票 | 固定 `need_evidence` | 营改增前后税目不同，需分段列示 |
| C18 | 时效切分与书面异议 | 按 `--as-of` 减 `--limit-years` | 时效外不等于必然不可协商；也不等于法院必然支持 |

## 4. 金额主张三层结构（写进函件）

- **A 层 · 可直接主张**：仅取 `status=hit` 且 `evidence_strength=强` 的条目金额。
  若没有，就写 **0 元**。实测多年的完整账 often 就是 0 元，这不影响函件价值。
- **B 层 · 条件性**：待银行提供 Q 项材料后，对未授权收费、未披露息费、计算差错再核算；
  明确「保留补充主张的权利」。
- **C 层 · 协商性**：时效内息费、积分补兑等，写成**协商请求**，明确「非认定法定退还义务」。

## 5. 自动复核清单（生成报告前逐条过）

- [ ] `validation.json` 的 `gate` 为 `pass`
- [ ] `isolation_report.json` 的排除样例已人工复核，无其他银行混入
- [ ] 年度表合计 = 总量；分类合计 = 逐笔总额
- [ ] 利息名目已注明包含关系，不重复加总
- [ ] 「疑似重复」「隐含利率偏高」均标注为待核实线索
- [ ] 对银行有利的事实（未检出项、整改事实）已如实写入
- [ ] `do_not_cite` 的说法一条都没出现在函件正文
- [ ] 所有金额均为 `Decimal` 两位小数，无 float 取整
- [ ] 报告内每个关键数字都能在 CSV 里逐笔回算
- [ ] 已扫描工作目录，无凭据 / 无真实账单被打包进待发布的仓库

# 邮箱准备、银行补寄话术与隐私规范

## 1. 让银行补寄完整历史账单

多数银行 App / 网银只能查近 12–24 个月，更早的账单需要人工申请补寄。
向客服（信用卡背面电话）或在线人工客服提出，通常 24 小时内以邮件附件形式发送，
每月一份 PDF，主题一般含「YYYY年MM月 综合对账单 / 补寄对账单」。

### 可直接照抄的话术

> 本人申请补寄本人名下信用卡 **自 YYYY 年 MM 月至 YYYY 年 MM 月** 的**全部月度对账单**
> （含无交易的空账期），以 PDF 附件形式发送至本人预留电子邮箱。
> 请一并书面告知：本卡卡种、历年适用年费标准与减免条件、现行及历版资费公示的查询路径、
> 本卡透支利率与分期年化利率的适用依据。
> 依据《商业银行信用卡业务监督管理办法》第 60、67 条及《消费者权益保护法》第 8 条，
> 请完整提供，勿以「系统仅保留近 N 年」概括答复；如确有部分无法提供，请逐项书面说明。

### 三个必须提醒用户的点

1. **确认账期连续**：逐月核对，记录缺月。无交易的「空账单」是正常期次，不算缺月。
2. **确认补寄已投递完毕**：银行可能分批发送，先扫一遍邮件头再开始下载，避免只拿一半。
3. **QQ 邮箱的「收取选项」**：网页版设置 → 账号 → POP3/IMAP/SMTP 服务下方，
   把「邮件收取范围」改为**全部**，并勾选「我的文件夹」。
   QQ 邮箱默认只同步近期邮件，不设这一步，十几年前的老账单可能根本拉不到。
4. **只处理本次补寄的邮件**：按收件日期（`--since`）与发件人域名双重限定，
   并复核 `isolation_report.json` 中被排除的银行类邮件。

## 2. 授权码 ≠ 邮箱登录密码

第三方客户端（IMAP/POP3/SMTP）必须使用**应用专用授权码**，用登录密码会直接返回
`AUTHENTICATIONFAILED`。这一步不要反复重试，会触发风控。

| 邮箱 | IMAP 主机 | 端口 | 授权码获取路径 |
|---|---|---|---|
| QQ 邮箱 | `imap.qq.com` | 993 | 设置 → 账号 → POP3/IMAP/SMTP 服务 → 开启「IMAP/SMTP 服务」→ 短信验证 → 生成 16 位授权码 |
| 163 / 126 | `imap.163.com` / `imap.126.com` | 993 | 设置 → POP3/SMTP/IMAP → 开启 IMAP → 新增授权密码 |
| Gmail | `imap.gmail.com` | 993 | Google 账号 → 安全性 → 两步验证 → 应用专用密码（App Password） |
| Outlook / Hotmail | `outlook.office365.com` | 993 | 账户安全 → 应用密码（需开启双重验证） |
| 腾讯企业邮 | `imap.exmail.qq.com` | 993 | 设置 → 邮箱绑定 → 客户端专用密码 |
| 新浪 | `imap.sina.com` | 993 | 设置 → 客户端授权密码 |

自定义主机用 `--provider custom --host <host> --port <port>`。

## 3. 凭据处理的硬性规则

- **只从环境变量读取**，变量名默认 `MAIL_USER` / `MAIL_TOKEN`，可用
  `--user-env` / `--token-env` 改。绝不写成命令行参数（会进入 shell history / 进程列表），
  绝不写入任何文件、配置、日志、notebook 或记忆。
- 环境变量在命令前临时导出即可，例如
  `MAIL_USER=... MAIL_TOKEN=... python3 scripts/run_pipeline.py ...`。
- 取数脚本不会保存邮箱地址、密码或授权码到 `mail_index.csv`、`manifest.csv`
  或任何 JSON；但**邮件头索引会包含发件人与主题**，属于个人数据，请勿随函外发。
- **取数完成立即撤销授权码**（同一设置页面可关闭服务 / 重新生成），
  若登录密码曾在对话中出现过，一并修改。
- 交付前扫描：
  `grep -rIl -e '<授权码>' -e '<密码>' .`（用真实值，且不要在共享终端里留历史）。

## 4. 只读取数保证

`fetch_bills.py` 的实现约束，修改时不得破坏：

- `M.select('"INBOX"', readonly=True)` —— 只读打开，不产生 `\Seen` 标志。
- `M.fetch(id, "(BODY.PEEK[])")` —— `PEEK` 而非 `BODY[]`，不会标记已读。
- 不调用 `store` / `copy` / `expunge` / `append`，不删除、不移动、不新增任何邮件。
- 失败重试有上限，避免被服务器判定为异常登录。

## 5. 不想给授权码时的替代路径

手动把全部账单 PDF 下载到一个文件夹，然后：

```bash
python3 scripts/run_pipeline.py --out ./audit_out \
  --from-dir ~/Downloads/statements --bank 你的发卡银行
```

`fetch_bills.py --from-dir` 会从文件名推断 `YYYY-MM`（支持 `2024年05月`、
`2024-05`、`202405` 等写法），推断不出会在 `fetch_report.json` 里逐条报错，
**改名后重跑即可**，不要靠猜。

## 6. 其他银行的隔离

邮箱里常常混有另一家银行的电子账单（例如「广州银行」与「广发银行」名称相近）。
`isolation_report.json` 会列出所有「看起来像银行邮件但被过滤掉」的条目，
**出具报告前必须逐条复核**。判断标准：

- 发件人域名是否属于目标银行官方域名；
- 主题是否为本次补寄对账单；
- 收件日期是否落在本次补寄窗口；
- 是否存在第三方营销域名冒用银行名义（这类邮件必须排除）。

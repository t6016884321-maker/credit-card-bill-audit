## 0. 最重要的一节：不得引用的说法

| 常见说法 | 为什么不能用 |
|---|---|
| 「逾期息费总额不得超过本金」 | 只出现在 2021 年**征求意见稿**，银保监规〔2022〕13 号**正式稿已删除**。引用会被银行当场驳回，并损害其余主张的可信度。 |
| 《银行卡业务管理办法》(银发〔1999〕17 号) 第 22、23 条滞纳金/复利 | 该规章**已于 2025-06-07 废止**。只能作为历史费率背景，不能作为现行主张依据。 |
| 「账单没显示年化利率，所以银行违法」 | 展示义务指向**协议、合同首页、办理页面、官网**，月度对账单不是法定展示位置。账单 0 次出现「年化」只能作为**间接证据**，用于索取当年披露材料。 |
| 「信用卡息费应参照民间借贷 LPR 四倍」 | 法释〔2021〕10 号未采用该标准；司法调减看综合息费是否过高，实践常参照年化 24%。 |
| 「分期手续费 / 循环利息一律可全额退回」 | 已充分告知且实际履行的息费通常不可退。可争的是未授权、未披露、计算错误、畸高调减。 |
| 「默认勾选 / 账单提示即视为同意」 | 监管明确整治「未经客户自主确认实施自动分期」；沉默原则上不构成承诺，账单是事后对账凭证不是事前要约承诺。 |

## 1. 时间轴（按对账口径切换规则）

| 时间 | 事件 | 对十几年账单的实际影响 |
|---|---|---|
| 2011-01 | 《商业银行信用卡业务监督管理办法》(银监会令 2011 年第 2 号) 施行 | 申请材料管理、领用合约必备条款、对账单与交易记录、差错争议处理的基础规则。**至今仍是索证的主要依据。** |
| 2014-08 | 《商业银行服务价格管理办法》(发改委、银监会令 2014 年第 1 号) | 第 18、19、25、34 条：收费须有明确服务内容、须公示、调价须提前告知、**客户确认后方可收费**。账单出现价目表上没有的名目可直接主张无依据。 |
| 2017-01-01 | 银发〔2016〕111 号施行 | **分水岭**：取消滞纳金与超限费；违约金须**双方协议约定**；年费、违约金、取现手续费、货币兑换费等**服务费用不得计收利息**；取消超限费。此后仍按旧名目收费是强证据。 |
| 2020 | 《银行业保险业消费投诉处理管理办法》(银保监会令 2020 年第 3 号) | **15 日内书面答复**、30 日上级机构核查、重大疑难可延长但须告知；第 13 条末句：**银行已掌握或可从内部档案获取的材料，不得要求投诉人提供**。 |
| 2021-01-01 | 银发〔2020〕327 号 | 取消信用卡透支利率上下限管理，改为由发卡机构与持卡人**自主协商确定**；要求以明显方式展示**年化利率**。老卡原合约常写「按人民银行有关规定执行」，银行往往拿不出逐户协商记录。 |
| 2021-05 | 法释〔2021〕10 号《关于审理银行卡民事纠纷案件若干问题的规定》 | 第 2 条：格式条款未尽提示说明义务可主张不成为合同内容；息费总额过高可请求调减。全额计息条款本身并不当然无效，但金额可调减。 |
| 2022-07-07 | 银保监规〔2022〕13 号《关于进一步促进信用卡业务规范健康发展的通知》 | （十八）分期须**事前独立申请、逐笔单独签订合同、以具有法律效力方式确认**；（七）（八）须告知申请表/合同查询渠道，签署材料**保存至业务存续期结束后至少 5 年**；（二十一）披露年化利率；（三十八）**6 个月内完成系统改造，改造后新增业务应符合本通知规定**；过渡期两年。监管新闻稿点名整治「未经客户自主确认实施自动分期」。 |
| 2023 | 《银行保险机构消费者权益保护管理办法》(2022 年第 9 号令) 施行 | 知情权、自主选择权、不得默认勾选/强制捆绑、销售行为可回溯、信息披露。 |
| 2024-07-07 | 13 号文两年过渡期届满 | 此后不应再以「过渡期存量业务」为由延续旧做法；但**过渡期不是新增业务的豁免期**（见（三十八））。核查时按合同成立日期而非账单声明日期分段。 |
| 2025-06-07 | 银发〔1999〕17 号废止 | 旧法条清理，见第 0 节。 |

## 2. 按争议点定位法条

| 争议 | 主要依据 | 要点 |
|---|---|---|
| 自动分期 / 默认开通 | 13 号文（十八）（三十八）；《民法典》496–498；《消法》9、26 | 账单中「已绑定」类表述是事后声明；要求逐笔授权、单独合同、法律效力确认、办理页面与年化披露页 |
| 年费与积分抵扣 | 服务价格管理办法 18、19、25、34；《消法》8 | 收费须公示且对应服务；多数银行规定**需客户主动申请兑换**且仅抵部分年费，通常没有自动全额抵扣义务；可追问历版规则与未兑换年度的提醒 |
| 单方调低额度 | 信用卡办法 50–52 条；13 号文（十三） | 银行并非绝对无权，但须说明调整类型（固定/临时）、触发原因、审批与通知；升降成对多为临时额度到期恢复 |
| 年化利率未展示 | 327 号文；13 号文（七）（二十一）；消保办法 22 条 | 展示位置是协议/合同首页/办理页面/官网，不是月度账单 |
| 循环利息 / 全额罚息 / 复利 | 111 号文；法释〔2021〕10 号第 2 条 | 服务费用不得计息；要求逐日计息明细、计息基数、还款冲抵顺序；息费过高可调减 |
| 违约金 | 111 号文 | 2017 起须另签协议，不能仅靠官网公告 |
| 索取原始申请材料 | 信用卡办法 35、37、60、67 条；13 号文（七）（八）；投诉办法 13 条 | 申请表须含领用合约、费用信息、醒目提示、本人抄录签名；签署材料须保存；银行不得要求客户提供自己掌握的材料 |
| 发票 | 《消法》22 条；《发票管理办法》(2023 修订)；财税〔2016〕36 号 | 利息按贷款服务、手续费按直接收费金融服务缴增值税；不得以「年代久远/未结清/个人不抵扣」拒开；拒开向 12366 反映 |
| 时效 | 《民法典》188、195 条 | 3 年普通时效、20 年最长保护期；书面异议可中断时效 |
| 举证妨碍 | 《最高人民法院关于民事诉讼证据的若干规定》第 95 条 | 控制证据一方无正当理由拒不提交，可主张推定对方主张成立 |
| 征信异议 | 《征信业管理条例》第 25 条 | 20 日内核查答复；每年两次免费信用报告 |
| 个人信息查阅复制 | 《个人信息保护法》第 45–48 条 | 查阅、复制、更正、删除、要求解释处理规则 |

## 4. 引用纪律

1. 引用**条、款、项**时先打开原文；律所网页与自媒体的转述出现过条文号错误。
2. 区分「正式稿 / 征求意见稿」「现行有效 / 已废止」「全国性规范 / 银行内部规则」。
3. 对银行有利的事实必须一并写进报告：例如 2017 年后无滞纳金、过渡期后未新开自动分期、
   分期均按期履行完毕。**只挑对自己有利的证据，会在第一次答复里被逐条反驳。**
4. 金额主张按「可直接认定 / 条件性 / 协商性」三层分开，不把协商空间写成法定必退。
